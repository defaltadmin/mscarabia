# Code of Conduct

## Our Pledge

We as members, contributors, and leaders pledge to make participation in the MSC Arabia project community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our Standards

### Positive behavior includes:
- Using welcoming and inclusive language
- Being respectful of differing viewpoints and experiences
- Gracefully accepting constructive criticism
- Focusing on what is best for the community and the project
- Showing empathy towards other community members
- Being professional in all communications
- Respecting the cultural context of Saudi Arabia and the wider MENA region

### Unacceptable behavior includes:
- The use of sexualized language or imagery, and sexual attention or advances of any kind
- Trolling, insulting or derogatory comments, and personal or political attacks
- Public or private harassment
- Publishing others' private information without explicit permission
- Other conduct which could reasonably be considered inappropriate in a professional setting

## Scope

This Code of Conduct applies within all project spaces, including:
- GitHub issues, pull requests, and discussions
- Code review comments
- Any public space where an individual is representing the project or its community

It also applies when an individual is officially representing the project in public spaces.

## Technical Standards

As a professional corporate website, all contributions must also meet these standards:

### Code Quality
- All HTML must be valid and semantic
- CSS must use the established design system (CSS custom properties)
- JavaScript must be clean, well-commented, and use `const`/`let` (not `var`)
- All interactive elements must have ARIA labels
- All new text must be added to both EN and AR translation objects

### Security
- No secrets, API keys, or credentials in code
- All user input must be sanitized
- All external links must use `rel="noopener noreferrer"` when `target="_blank"`
- CSP compliance — no new `unsafe-inline` additions without discussion

### Accessibility
- WCAG 2.2 AA compliance required for all changes
- Minimum 44px touch targets for interactive elements
- Color contrast ratios must meet AA standards
- All images must have meaningful `alt` text
- Keyboard navigation must work for all features

### i18n
- All user-facing text must use `data-i18n` attributes
- Both EN and AR translations must be provided
- RTL layout must be tested for any layout changes
- Arabic translations must be natural and professional

## Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported to the project maintainer at **info@mscarabia.com**.

All complaints will be reviewed and investigated promptly and fairly. The project team is obligated to maintain confidentiality with regard to the reporter of an incident.
